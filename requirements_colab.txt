# IndexTTS2 API Server — GOOGLE COLAB requirements (conflict-audited)
#
# Audited against the CURRENT Colab image (Python 3.12). The rules applied:
#   - NOTHING here touches torch/torchaudio/torchvision  -> Colab's CUDA-matched
#     builds stay intact (installing other builds is the #1 way people brick a
#     Colab GPU runtime).
#   - numpy/pandas/matplotlib/scipy/pillow/cv2/grpcio   -> left untouched, any
#     version Colab ships satisfies every package below (this same dependency
#     set is proven working under numpy 2.2.6 in the production env).
#   - only >= ranges / soft upper bounds                -> pip's default
#     "only-if-needed" strategy keeps Colab's preinstalls wherever possible;
#     no silent downgrades of system-critical packages.
#
# Colab setup cells:
#
#   # [1] install + verify NOTHING conflicts afterwards
#   !pip -q install -r requirements_colab.txt
#   !pip -q install -e .
#   !python -m nltk.downloader averaged_perceptron_tagger_eng punkt
#   !pip check                 # MUST print: "No broken requirements found."
#   !which ffmpeg              # /usr/bin/ffmpeg (preinstalled - do not install)
#
#   # [2] fetch checkpoints into ./checkpoints (your usual hf/modelscope script)
#
#   # [3] run  (T4: fp16 recommended; --share opens the public cloudflared URL)
#   !python api_server.py --model_dir ./checkpoints --device cuda --fp16 --share
#
# If `pip check` ever reports a clash: fix THAT package only, then re-run
# `pip check`. Never blanket-reinstall torch on Colab.
# =============================================================================
